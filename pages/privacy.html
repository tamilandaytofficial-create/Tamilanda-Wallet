Privacy & Security

🔐

Your Wallet Data

Tamilanda Wallet is designed as a local-first wallet. Your wallet information is currently stored inside this browser/device using local storage.

  • Accounts and balances
  • Income and expenses
  • Transactions
  • Buyer and EMI information
  • Money To Give records
  • Recurring payment information
Current storage LOCAL DEVICE
📱

No Cloud Account Required

The current version does not require you to create a Tamilanda account or sign in to use the wallet.

💾

Backup & Restore

You can create a backup of your wallet data from Settings and restore it later.

Important Keep your backup file in a safe place. Anyone who gets access to an unencrypted backup may be able to read the wallet information inside it.
🛡️

Security Roadmap

Additional security features can be added as the wallet grows.

  • App PIN lock
  • Biometric unlock
  • Encrypted backup
  • Secure restore confirmation
  • Session/app lock
Advanced security PLANNED
🗑️

Your Data Control

You can export your wallet backup or clear the wallet data from the Settings page.

Before deleting Always create a backup if you may need the wallet data again in the future.
